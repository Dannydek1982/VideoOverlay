# Jaren 80-schil

Live camera-overlay die herkende objecten pixel-precies een jaren 80-uiterlijk geeft: auto's krijgen jaren 80-lak met sierstreep, mensen een neon trainingspak, fietsen felle kleuren. Plus VHS-filter en synthmuziek. Draait volledig in de browser van je telefoon, er gaat geen beeld naar een server.

Open https://dannydek1982.github.io/VideoOverlay/ in Safari op je iPhone en tik op "Start live camera".

- `index.html`: de app
- `mp/`: MediaPipe Tasks Vision 0.10.14 (Apache 2.0)
- `model/deeplab_v3.tflite`: DeepLab v3 segmentatie (Apache 2.0), 2,7 MB
