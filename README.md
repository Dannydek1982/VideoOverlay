# Jaren 80-schil

Live camera-overlay die herkende objecten (auto, fiets, persoon, ...) vervangt door jaren 80-versies, met VHS-filter en synthmuziek. Draait volledig in de browser van je telefoon (TensorFlow.js + COCO-SSD), er gaat geen beeld naar een server.

Open de GitHub Pages-link in Safari of Chrome op je telefoon en tik op "Start live camera".

- `index.html`: de app
- `lib/`: TensorFlow.js 4.20.0 en coco-ssd 2.2.3 (Apache 2.0)
- `model/`: SSDLite MobileNet v2 gewichten (Apache 2.0)
